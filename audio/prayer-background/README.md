# Fundo musical para o Lugar Secreto

Coloque **um único** arquivo de áudio nesta pasta para servir de **fundo musical
opcional** durante a oração no **Lugar Secreto**.

- Formato recomendado: `.mp3` (ou `.ogg`)
- Nome sugerido: `prayer-background.mp3`
- Use apenas áudio **próprio ou devidamente licenciado**.

## Comportamento

- Se **existir** um arquivo aqui (e o administrador o disponibilizar), ele poderá
  ser tocado como fundo durante a oração.
- Se **não existir**, a oração continua funcionando normalmente — o fundo musical
  é sempre **opcional**. O usuário também pode usar o Som Ambiente gerado pelo app
  ou um link do YouTube configurado.

> Observação: esta pasta é a **fonte** do arquivo. A publicação/entrega do áudio
> ao app será definida na fase de backend (upload pelo painel administrativo).
> **Não** criamos aqui uma biblioteca/catálogo de músicas — apenas este único
> fundo para oração.
